# Telleroo

> Telleroo is a UK bulk payments platform that automates supplier and payroll payments for businesses, accountants and bookkeepers. It provisions a ring-fenced e-money wallet in the customer's name and sends bulk Faster Payments 24/7, plus international payments in 25+ currencies over SEPA, ACH and SWIFT, with Confirmation of Payee and multi-level approval workflows.

Note: Telleroo also publishes its own llms.txt at https://www.telleroo.com/llms.txt. This file is generated by the API Evangelist enrichment pipeline from the catalog profile and repo artifacts.

## APIs

- [Telleroo Business API](https://docs.telleroo.com/): RESTful API (v1) to automate outbound payments from your own account — recipients, accounts, transactions and bank transfers. Base URL https://api.telleroo.com. Token auth via the Authorization header.
- [Telleroo Partner API](https://partner-docs.telleroo.com/): RESTful Embedded Payments API (v3) to build pay runs into your own platform on behalf of client companies. Base URL https://api.telleroo.com. OAuth 2.0 (authorization code, scope create).
